## 为什么用GitHub学英语

- **真实语料**：README、Release Notes、Issue、Commit Message 全是母语开发者写的真实英语，不是教材英语；
- **免费海量**：全球上亿公开仓库，任何兴趣领域都有；
- **双语对照**：大量知名项目提供中英双语 README / 官方文档，天然对齐；
- **一鱼两吃**：学英语的同时积累专业术语，直接服务专业能力；
- **句子不孤立**：每句话都有真实场景，学完就能用。

## 核心能力

1. **选仓**：按兴趣、难度（生词率 ≤15%）、双语三原则，从你的领域锁定 1 个仓库；
2. **采句**：从 README / Release Notes / Issue / Commit Message 采集 3–5 句真实英语；
3. **建卡**：每句一张四段式句子卡（原句 / 出处 / 拆解 / 复用）；
4. **复盘**：每日回顾、每周句式聚类、每仓 100 词英文 summary，掌握度 5 级自评；
5. **人机协同**：AI 施工队查词改写，AI 陪练模拟项目维护者对话与造句打分，人类验收把关。

## 环境与依赖

- 无需安装任何软件；
- 需要一个 GitHub 仓库作为语料（公开仓库即可，可用自己的 `knowledge-palace-glossary` 起步）；
- 学习卡片存为 Markdown 文件，任何编辑器可读。

## 快速上手（三步）

1. **选仓**：说"用GitHub学英语，开始选仓"，给出你的兴趣领域；
2. **采句建卡**：说"从 <仓库名> 采句"，AI 读取仓库并采 3–5 句；再说"做成卡片"；
3. **复盘**：次日说"复盘昨天的句子卡"，遮拆解自译，标记掌握度。
