# 仓库选择清单 · Repo Selection Checklist

> 用GitHub学英语 · 第一步"选仓"配套工具。选仓前逐项勾选，三项全过再锁定。

## 选仓三原则

| # | 原则 | 检查动作 | 通过标准 |
|---|------|----------|----------|
| 1 | 兴趣优先 | 问自己：这个仓库讲的东西，我是否真正想读懂？ | 想读懂，即使现在不懂 |
| 2 | 难度匹配 | 读 README 前 200 词，查 10 个生词 | 认识 ≥8 个（生词率 ≤15%） |
| 3 | 双语优先 | 查看仓库是否提供中英双语 README / 官方文档 | 有双语可对照，或英单语但句式标准 |

## 难度判定

- 10 个生词认识 ≥8 个 → 合适，锁定；
- 认识 5–7 个 → 偏难，可配双语对照硬啃，或换仓；
- 认识 <5 个 → 太难，换仓；换仓后仍难，降难度选更小工具类仓库。

## 采句位置优先级

1. README.md（标准项目英语）
2. Release Notes（真实时态与功能描述）
3. Issue 讨论（真实对话语气）
4. Commit Message（精炼动宾短语）

## 推荐起点（可按领域替换）

| 类型 | 示例 |
|------|------|
| 自己的仓库 | knowledge-palace-glossary（中英双语术语表） |
| 知名双语项目 | Vue / React 中文文档、VS Code、GitHub Docs |
| 工具类小仓 | 你在用的效率工具、命令行工具 |
