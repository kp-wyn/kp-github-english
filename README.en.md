# Learn English with GitHub · kp-github-english

> 5th member of the "X-It" lightweight skill family · learning-loop skill
> Use GitHub open-source repositories as a real-world English corpus, and learn with a five-step loop: Pick a repo → Collect sentences → Build cards → Review → Human-AI collaboration.

**中文说明:** [README.md](./README.md)

---

## Why Learn English with GitHub

- **Real corpus**: READMEs, release notes, issues, and commit messages are real English written by native-speaking developers — not textbook English;
- **Free and massive**: hundreds of millions of public repositories cover any field you care about;
- **Bilingual pairs**: many popular projects ship bilingual READMEs or official translations, giving you a natural side-by-side check;
- **Two birds, one stone**: build professional vocabulary while learning English;
- **Sentences in context**: every sentence has a real scenario, so what you learn is what you can use.

## Core Capabilities

1. **Pick a repo**: lock one repository by interest, difficulty (≤15% unknown words), and bilingual availability;
2. **Collect sentences**: gather 3–5 real sentences from README / Release Notes / Issues / Commit Messages;
3. **Build cards**: turn each sentence into a four-part card (original / source / breakdown / reuse);
4. **Review**: daily recall, weekly pattern clustering, and a 100-word English summary per repo, with a 5-level mastery self-check;
5. **Human-AI collaboration**: AI team explains words and rewrites; AI practice partner simulates maintainer chat and scores your sentences; humans do final verification.

## Environment & Dependencies

- No installation required;
- One GitHub repository as corpus (public is fine; you can start with your own `knowledge-palace-glossary`);
- Cards are saved as Markdown files, readable by any editor.

## Quick Start (3 Steps)

1. **Pick**: say "Start learning English with GitHub" and name your field of interest;
2. **Collect & build**: say "Collect sentences from <repo>" — the AI reads the repo and picks 3–5 sentences; then say "turn them into cards";
3. **Review**: the next day say "review yesterday's cards", cover the breakdown, translate, and mark your mastery level.
